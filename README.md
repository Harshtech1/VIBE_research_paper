# VIBE: Variational Information Bottleneck for Group Emotion Recognition
## Reproduction of the ICML 2026 Research Paper

> **Repository Status:** ✅ Reproduction Complete (v1.0)

---

## Overview

This repository contains a complete reproduction of the VIBE (Variational Information Bottleneck for Emotion) framework for Group Emotion Recognition (GER) using the publicly available GECV dataset.

The reproduction includes:

- Dataset preprocessing
- Primitive extraction
- Multimodal VIBE model
- End-to-end training pipeline
- Evaluation pipeline
- Automatic report generation
- Training visualizations
- Publication-ready analysis

## Reproducibility Notes

The public GECV release does not include an official held-out test split.

This reproduction evaluates the model using the validation split generated by the repository pipeline.

The complete evaluation pipeline, generated reports, and visualizations are included in this repository.
